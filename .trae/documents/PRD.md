# 配件位置记忆工具 - 产品需求文档

## 1. 产品概述

一款面向工厂库管人员的配件位置管理工具，帮助用户记录、查找和管理仓库中设备组装所需配件的存放位置、规格与数量信息，解决"仓库面积大、找不到配件"的核心痛点。

- 目标用户：工厂组装设备岗位的库管人员
- 核心问题：仓库面积大、不熟悉布局、配件难找、规格与中文名称需对应
- 价值：把"靠记忆找配件"变成"靠数据找配件"，提升领料效率，减少出错

## 2. 核心功能

### 2.1 功能模块

1. **配件台账页面（首页）**：配件列表、快速搜索、筛选、统计概览
2. **新增/编辑配件页面**：录入配件信息（中文名、规格、位置、数量、分类、备注）
3. **配件详情页面**：查看完整信息、位置指引、出库记录、编辑入口

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|

| 配件台账（首页） | 配件列表表格 | 表格展示：编号、中文名、规格、库区、货架、层、位、库存数量、状态，行内快捷操作 |

## 3. 核心流程

**主流程：工人领料**
1. 工人报出需要的配件名称和规格
2. 库管在首页搜索框输入名称/规格关键字
3. 系统实时筛选并展示匹配配件，显示位置路径
4. 库管点击查看详情，按位置指引前往取件
5. 核对数量后，在详情页执行"出库"操作，输入数量与领用人
6. 系统自动扣减库存并生成出库记录

**录入流程：新配件入库登记**
1. 点击浮动"+"按钮进入新增页面
2. 录入中文名、规格、分类等基本信息
3. 结构化选择/输入库区、货架、层、位
4. 填写初始数量与安全库存
5. 保存，配件进入台账

## 4. 用户界面设计

### 4.1 设计风格

- **风格定位**：工业实用风（Industrial Utilitarian）—— 强调功能性、高可读性、清晰的信息层级，适合仓库现场使用
- **主色调**：深工业灰（#1f2937）为骨架，安全警示黄（#facc15）为强调色，用于关键操作与位置标识
- **辅助色**：白底/浅灰底承载表格数据，库存预警用警示橙红（#ef4444），正常状态用工业蓝（#3b82f6）
- **按钮风格**：直角或微圆角（2-4px），扁平实心，主操作按钮黄色高对比
- **字体**：标题用思源黑体粗体（Noto Sans SC Bold），正文用思源黑体常规，编号/规格/位置用等宽字体（JetBrains Mono）增强可读性
- **布局**：顶部导航 + 左侧筛选 + 主内容表格的桌面优先布局，信息密度适中
- **图标**：线性图标风格，与工业感一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 配件台账 | 顶部导航 | 深灰背景，左侧 logo+标题"配件仓位管家"，右侧统计胶囊 |
| 配件台账 | 搜索栏 | 大尺寸搜索输入框，黄色搜索按钮，占位符提示"输入中文名/规格/位置" |
| 配件台账 | 统计卡片 | 4个数据卡片横排：配件总数、低库存预警、库区数、今日出库 |
| 配件台账 | 筛选侧栏 | 库区多选、分类下拉、排序方式，浅灰卡片容器 |
| 配件台账 | 配件表格 | 斑马纹表格，表头深灰，行hover高亮，位置列用等宽字体+黄色标签 |
| 新增/编辑配件 | 表单卡片 | 分组卡片：基本信息、位置信息、库存设置，字段清晰对齐 |
| 配件详情 | 位置指引 | 大字号黄色卡片，等宽字体显示完整位置路径，带方向感装饰 |
| 配件详情 | 出库记录 | 时间线样式列表，显示每次出库详情 |

### 4.3 响应式

- 桌面优先（仓库现场多用台式机/笔记本）
- 平板自适应（折叠侧栏为顶部下拉）
- 移动端基础可用（表格转为卡片列表）

## 5. 数据存储

- 采用浏览器 localStorage 本地持久化，无需后端服务器，适合工厂内网/离线使用
- 支持数据导出（JSON）与导入，便于备份和迁移
